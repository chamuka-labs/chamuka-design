# Colour and contrast

Two themes, one system. **Dark** (warm near-black `#12100E`, cream text) is the default; **light "paper"** (`#F2EAD9`, ink text) is the same system with different roles. With no attribute the theme follows `prefers-color-scheme`; `data-theme="dark|light"` forces it. Use the Theme switch in the toolbar.

Components use roles only (`--db-bg`, `--db-surface`, `--db-raised`, `--db-border*`, `--db-fg*`, `--db-accent*`, `--db-focus`). Raw palette values are for specimens.

**Ember `#E24E1B` is the only accent.** It fills the primary button, numbers sections and draws rules. Text on ember is always ink `#12100E` (4.8:1; 6.2:1 on the hover fill `#F06A3A`). Cream or white on ember fails, so never use them.

- Small ember text on dark: `#E24E1B` on bg/surface, `#F06A3A` on raised.
- Small ember text on paper: `--db-accent-text` `#A8340E` (5.6:1). True ember on paper is 3.3:1, so it is for fills, rules, dots and badge edges only.
- Focus: 2px outline, 2px offset. `#F06A3A` on dark, `#A8340E` on light.

Gold, slate, mineral, forest and coral are **signal** colours: diagrams and 8px status dots only. Never buttons, links or headings.

No gradients, glows, shadows, pure white or pure black.

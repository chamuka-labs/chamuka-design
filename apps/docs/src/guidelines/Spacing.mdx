# Spacing

The scale is 4px: 0, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96.

| Use | Token |
|---|---|
| Icon-to-label | `2` (8px) |
| Field label to control | `1` (4px) |
| Related controls | `3`–`4` |
| Card padding | `6` (24px) |
| Page section | `8`–`12` |

Daybreak v2 is near-square: buttons, inputs and chips 2px (`rounded-md`), panels, cards and dialogs 4px (`rounded-lg`, `--radius`). `full` is for 8px status dots, radios and spinners only. Section rhythm is `--db-section` (96→192px).

Do not space by eye with odd pixels. If 16px is tight and 24px is loose, 20px (`5`) is the in-between.

# Daybreak design system

**Chamuka Labs is an applied AI lab: we ship AI-native products, put research into practice, and build tools for AI agents.**

Daybreak is brand infrastructure for [Chamuka Labs](https://chamuka.ai) — not a product. **DrawIt**, FormIt, Play, Waypoint, Vmette and others are experiments or infrastructure, not launched products. DrawIt is an experiment under agent and human interaction. This Storybook is the UI/UX source for that system, now on **Daybreak v2**: warm dark by default with a light "paper" theme (use the Theme switch in the toolbar), ember as the only accent, Archivo condensed display, Plex Sans body, Plex Mono interface labels, hairline borders and no shadows. Spec: `brand/daybreak-v2/SPEC.md`. Logo masters, print files, and Python generators live in `/brand`. Digital templates live in `/templates`.

**Audience:** business teams. **Feel:** playful, warm, African-rooted — not toy-like. **Voice:** founder-led, short, specific, slightly dry. **“From thoughts to form”** is DrawIt’s line only.

## Packages

| Package | Use |
|---|---|
| `@chamuka/tokens` | DTCG tokens → CSS variables, Tailwind v3 preset, Tailwind v4 `@theme`, TS |
| `@chamuka/ui` | React 19 components (Tailwind + UI SDK) |
| `@chamuka/icons` | Daybreak mark, lockups, product marks |

Consuming apps (DrawIt and other lab surfaces) are Next.js + React 19 + Tailwind v3 or v4 with shadcn-style CSS variables. Import `tokens.css` + `theme.css` + `fonts.css`, `@source` `@chamuka/ui` (or import the compiled `styles.css` fallback), then wrap with `ThemeProvider`. Interactive components wrap UI SDK; presentational ones are plain Tailwind.

## Quick start

See the repository README for Tailwind v3 and v4 wiring. In JSX:

```tsx
import { ThemeProvider, Button } from "@chamuka/ui";

<ThemeProvider>
  <Button>Save</Button>
</ThemeProvider>
```
